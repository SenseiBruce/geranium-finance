# Zip archives

Superseded `inputs.zip` and `golden.zip` files are copied here automatically whenever `package_zips.py` or `gf gate` rebuilds a zip.

Each subfolder is named `YYYYMMDD-HHMMSS` (local time when the new zip was created).

**Upload to the platform:** use `../submission/` or the latest zips at the task root — not these archives.
